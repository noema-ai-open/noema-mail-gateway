# Code of Conduct

## Our standard

Participants are expected to communicate respectfully, review technical claims
in good faith and protect the privacy and security of everyone whose data could
be affected by the project.

Acceptable behavior includes:

- constructive, specific technical feedback
- respect for different experience levels and accessibility needs
- careful handling of security reports and personal information
- correcting mistakes without harassment or humiliation
- documenting assumptions, risks and limitations honestly

Unacceptable behavior includes:

- harassment, threats, discrimination or sexualized conduct
- publishing another person's private information
- posting credentials, real mailbox content or attachments
- using the project to access a mailbox without authorization
- pressuring maintainers to weaken security boundaries
- deliberately misleading claims about provider support or test coverage

## Scope

This code applies to repository discussions, pull requests, issues, reviews,
security reports and project-related public communication.

## Enforcement

Report conduct concerns privately to the repository owner. Do not include
credentials or personal mail content in the report. Maintainers may edit or
remove content, close discussions, reject contributions or temporarily or
permanently restrict participation when necessary to protect people or the
project.

Enforcement decisions should be proportionate, documented and focused on
safety rather than public punishment.
